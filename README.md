# Hlegal Website Project

## 📝 Опис проєкту
Це багатосторінковий адаптивний веб-сайт для юридичної компанії "Hlegal".
Проєкт складається з двох ключових сторінок:
1.  **Home (`home.html`)** — Головна сторінка зі складною структурою, градієнтними фонами та інтерактивними елементами.
2.  **Team (`team.html`)** — Сторінка команди з адаптивною сіткою карток співробітників.

Сайт повністю адаптований під різні типи пристроїв (Mobile, Tablet, Laptop, Desktop).

## 🛠 Технології та Інструменти
* **HTML5** (Семантична верстка)
* **SCSS (SASS)** (Препроцесор для стилізації)
* **BEM** (Методологія іменування класів: Block-Element-Modifier)
* **Flexbox** та **CSS Grid** (Побудова макетів)
* **Mobile-First / Desktop-First** (Адаптивна стратегія залежно від секцій)

## 📂 Структура проєкту (SCSS Архітектура)
Проєкт побудований на модульній системі стилів. Основні файли розбиті на логічні частини:

### 1. Загальні (Common)
Файли, що використовуються на всіх сторінках:
* `_variables.scss` — Єдине джерело правди для кольорів, шрифтів, градієнтів та брейкпоінтів.
* `_mixins.scss` — Міксини для адаптиву (`mq`), декоративних крапок (`dot`) та іконок.
* `_reset.scss` — Глобальне скидання стилів та фікс горизонтального скролу.
* `_fonts.scss` — Налаштування типографіки.

### 2. Компоненти та Секції
* `_header.scss` / `_footer.scss` — Стилі для шапки та підвалу сайту (спільні для обох сторінок).
* `_main.scss` (для Team) — Сітка карток команди.
* `home.scss` (або відповідні паршали) — Специфічні стилі головної сторінки (Services, Clients, Publications).

## 🚀 Ключові особливості реалізації

### 🎨 Дизайн (UI)
* **Градієнти:** Реалізовано складні градієнти:
    * `background: radial-gradient(...)` для загального фону.
    * `background-clip: text` для текстових заголовків (ефект тексту з градієнтом).
* **Декор:** Автоматизоване створення декоративних розділювачів (крапок) у списках та контактах через SCSS міксини.

### 📱 Адаптивність (UX)
Верстка підтримує брейкпоінти: `1680px`, `1400px`, `992px`, `768px`.

**Особливі мобільні рішення:**
1.  **Горизонтальний скрол:** Секція "Services" на мобільних пристроях перетворюється на свайп-контейнер (`overflow-x: auto`), що є зручним патерном для тач-скрінів.
2.  **Адаптивні сітки (Grids):**
    * Блок "Clients" перебудовується з 4 колонок у 1.
    * Блок "Team" адаптується з 3 колонок у 1 вертикальну колонку.
3.  **Фікс переповнення:** Використано `overflow-x: hidden` на рівні `body`, щоб уникнути небажаного горизонтального скролу сторінки.

## 💻 Інструкція із запуску

Для розгортання проєкту на локальній машині:

1.  **Завантажте файли:**
    Клонуйте репозиторій або завантажте архів з файлами.

2.  **Компіляція SCSS:**
    * Переконайтеся, що у вас встановлено **Live Sass Compiler** (для VS Code) або Node.js Sass.
    * Запустіть "Watch Sass" для компіляції файлів `.scss` у `.css`.
    * *Важливо:* Не редагуйте `.css` файли напряму, змінюйте тільки `.scss`.

3.  **Перегляд:**
    Відкрийте файл `index.html` (для головної) або `team.html` (для команди) у будь-якому сучасному браузері.
